Privacy Policy

Family Agent · Last updated 28 October 2026

Who uses this app

Family Agent is a private, non-commercial assistant run by and for a single household. It is not available to the public.

What data it accesses

With the account holder's permission, Family Agent uses the Google Calendar API to read and create events on the household calendar that has been explicitly shared with it. It does not access Gmail, Google Drive, contacts or any other Google data.

How data is used

Calendar data is used only to answer the household's questions about their schedule and to add or update events when a household member asks and confirms. Data is not sold, shared with third parties, used for advertising, or used to train AI models.

Where data is stored

Google sign-in tokens are stored only on the household's own computer. Calendar contents are processed when a request is made and are not stored elsewhere by this app.

Google API Services User Data Policy

Family Agent's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from Google Account → Third-party apps & services.
